# 프레이밍 라벨링 가이드라인 v3

**과제**: 한국어 경제 뉴스 3분류 (긍정 / 중립 / 부정)
**용도**: 평가자 간 신뢰도(IAA) 측정용 — 평가자 2인이 각자 독립적으로 150건 라벨링
**작성**: 조아람 (20233506, 순천향대 컴퓨터소프트웨어공학과) · 2026-09-02

---

## 0. v2에서 바뀐 것

파일럿 검증(50건 × 2회)에서 발견된 오류를 반영했다.

| # | 변경 | 발견 경위 |
|---|------|-----------|
| 1 | **R0-a 강도어 방향 규칙 신설** | `금리 최고치`·`금리 돌파`를 긍정으로 오분류하는 사례 다수 |
| 2 | **R0-b 인용문 처리 규칙 명문화** | "인터뷰는 어떻게 판단하나" 질문 반복 |
| 3 | 평가어 예시를 실제 오류 사례로 교체 | 사전에 없는 평가어(`지독한`,`주름진`)를 놓침 |
| 4 | 극성 사전을 **참고용**으로 격하 | 사전 의존 시 강도어 오류 발생 |

---

## 1. 판단의 출발점 — 평가어를 먼저 찾는다

이 과제는 **"사건이 좋은가 나쁜가"를 묻지 않는다.**
**"기자가 이 사건을 어떤 표현으로 서술했는가"** 를 묻는다.

```
[1] 제목과 리드에서 평가어를 찾는다
        ↓
[2] 평가어가 없다 ────────────────────→ 중립
        ↓
[3] 평가어가 있다 → 어느 방향인가?
        ├─ 성장·회복·안도 ─────────────→ 긍정
        ├─ 둔화·우려·위기 ─────────────→ 부정
        └─ 양쪽이 비슷하게 병기 ────────→ 중립
```

### 평가어란
그 단어를 빼도 **사실이 그대로 남는** 표현. 즉 기자의 해석이 실린 말.

| 문장 | 판정 |
|------|------|
| 성장률 0.7% **기록** | 사실어 (빼면 문장 불성립) |
| 성장률 0.7% **그쳐** | **평가어** (부족하다는 기자의 판단) |
| 물가 5.7% **상승** | 사실어 |
| 물가 5.7%로 **주춤** | **평가어** |

---

## 2. 판정 규칙 — **번호가 낮을수록 우선**

> 규칙이 충돌하면 반드시 번호가 작은 규칙이 이긴다.

### R0. 사건이 아니라 서술을 본다 (최상위)

사건 자체의 호재/악재는 판단 대상이 **아니다.**
나쁜 사건이라도 건조한 사실 전달이면 **중립**이다.

```
✗ 대출 규제 강화 → "규제는 나쁘니까" → 부정
○ 대출 규제 강화 → 평가어 없이 조치 내용만 전달 → 중립
```

#### R0-a. 강도어는 방향이 없다  ← v3 신설

`급등` `최고치` `돌파` `치솟` `급증` `사상최대` 등은 **크기**만 나타낸다.
**무엇이** 그렇게 되었는지에 따라 방향이 정반대가 된다.

| 오르면 **긍정** | 오르면 **부정** |
|----------------|----------------|
| 주가 · 수출 · 취업자 · 실적 · 흑자 · 소비 | **금리 · 물가 · 부채 · 환율 · 실업률 · 적자** |

```
✗ "美 국채금리 15년 만에 최고" → '최고치'는 긍정어 → 긍정
○ "美 국채금리 15년 만에 최고" → 금리 상승은 부담 → 부정
```

> 하락도 같다. `환율 하락`은 원화 강세이므로 부정이 아니다.
> 본문의 `달러 약세`는 달러 이야기이지 한국 경제 이야기가 아니다.

#### R0-b. 인용문은 기자의 평가가 아니다  ← v3 신설

큰따옴표 안의 말은 **취재원의 것**이다.
기자 서술에 평가어가 없고 인용만 있으면 → **중립**

```
○ 옐런 "경제 여건 강화됐다"…구체적 시점은 안 밝혀  → 중립
```

**단, 기자가 그 인용을 제목으로 뽑았다면** 편집 판단이 개입한 것이므로
R1(제목 우선)을 적용한다.

### R1. 제목 우선
제목과 본문의 프레임이 충돌하면 **제목**을 따른다. (독자 노출도)

### R2. 병렬 제시면 중립
긍정 요소와 부정 요소가 비슷한 비중으로 병기되고,
기자가 **어느 쪽으로도 결론짓지 않으면** → **중립**

판정 테스트 — 하나라도 해당하면 병렬:
- 제목이 `A…B도` / `A에도 B` / `A지만 B` 구조
- 좋은 소식과 나쁜 소식이 비슷한 분량으로 각각 서술
- 상반된 전망을 균형 인용

### R3. 결론 우선
앞뒤 방향이 다르고 기자가 **한쪽으로 분명히 결론을 냈다면** 그 방향.
결론을 내지 않았다면 **R2(중립)가 우선**한다.

### R4. 그래도 판단이 서지 않으면
**중립**으로 두고 `애매함`을 표시한 뒤, 이유를 메모에 남긴다.

## 3. 실제 오류 사례 (파일럿에서 수집)

### A. 강도어 방향 오류 (R0-a)

| 제목 | 잘못된 판정 | **정답** | 이유 |
|------|------------|---------|------|
| 美 10년물 국채금리 15년 만에 **최고**…주담대금리 7% 넘어 | 긍정 | **부정** | 금리 상승 = 차입 부담 |
| **실망 준** 파월에 미 국채금리 또 1.5% **돌파** | 긍정 | **부정** | 제목에 '실망 준' 명시 |
| 원/달러 환율 **하락** 마감…달러당 1,183원 | 부정 | **중립** | 환율 하락은 원화 강세, 게다가 순수 시황 |

### B. 사건의 좋고 나쁨으로 판단 (R0)

| 제목 | 잘못된 판정 | **정답** |
|------|------------|---------|
| 용인시, 희망드림일자리사업 참가자 300명 모집 | 긍정 | **중립** |
| 농협·신협 부동산건설업 대출 총대출 30% 이내 제한 | 부정 | **중립** |
| 광주 북구, 경기침체 겪는 소상공인 지원 | — | **중립** ✓ |

### C. 평가어 누락 — 사전에 없는 표현

| 제목 | 놓친 평가어 | **정답** |
|------|------------|---------|
| 홍남기의 50분 부동산 정책 옹호…**해법 없이 당부만 있었다** | 해법 없이 당부만 | **부정** |
| **지독한** 불확실성…오늘밤 나올 美 지표들 | 지독한 | **부정** |
| 소주·맥주 줄줄이 인상... **주름진** 가계 물가 | 주름진 | **부정** |
| 국가·기업·가계부채 4,539조···**빚 굴레에 짓눌린** 대한민국 | 짓눌린 | **부정** |

> **극성 사전은 참고용일 뿐이다.** 기자가 감정을 실은 표현이면 사전에 없어도 평가어다.

### D. 올바른 중립 판정

| 제목 | 이유 |
|------|------|
| 코스피-코스닥 하락, 원/달러 환율 상승 | 순수 시황, 평가어 없음 |
| 7월 취업자 54만명 증가…숙박·음식점 등 대면업종은 **감소** | R2 병렬 |
| 日·유로존 2분기 경제성장률 및 7월 CPI 관심 | 예고 기사 |

## 4. 참고 — 평가어 사전 (198개, 참고용)

**긍정** — 강: 고공행진·급등·최고치·폭등·호황·사상최대 / 중: 강세·개선·돌파·반등·선방·성과·청신호·호조·훈풍·흑자 / 약: 견조·기대·안도·안정·양호·완화·회복력

**부정** — 강: 급락·붕괴·위기·적신호·직격탄·참사·추락·패닉·폭락 / 중: 둔화·먹구름·부진·악화·위축·저조·적자·타격·하락·한파 / 약: 경계·논란·리스크·부담·불안·불확실·압박·우려·주춤·충격·한계

> ⚠️ 강도어(`급등`,`최고치`,`돌파`,`급증`)는 **R0-a**를 반드시 함께 적용할 것.
> ⚠️ 주제어(`성장`,`부채`,`침체`,`물가인상`)는 event_type 명칭이므로 평가어가 **아니다.**

## 5. 라벨링 절차

1. 도구에서 **평가자(A/B)** 를 선택한다
2. 기사마다:
   - 평가어를 찾아 입력칸에 적는다 (없으면 `평가어 없음`)
   - R0 → R0-a → R0-b → R1 → R2 → R3 → R4 순으로 적용
   - 라벨 선택 (`1` 긍정 / `2` 중립 / `3` 부정)
   - 애매하면 `E` + 메모
3. 150건 완료 후 CSV 내보내기

### 지켜야 할 것
- **상대방의 라벨을 절대 보지 않는다** (도구가 차단하지만 구두로도 공유 금지)
- **라벨링 중 서로 상의하지 않는다** — 독립성이 깨지면 κ가 무효
- 불일치 조정(adjudication)은 **양쪽이 150건을 모두 끝낸 뒤에** 한다

---

## 6. 이후 절차

```
평가자 A(조아람) 150건  ─┐
                        ├→ Cohen's κ 산출  ← 논문 보고 수치
평가자 B(친구)   150건  ─┘
         ↓
   불일치 건 토론(adjudication) → Gold Set 150건 확정
         ↓
   Gold Set ↔ LLM 자동 라벨 대조 → LLM 타당성 검증
```

> κ는 **토론 전 원본 라벨**로 계산한다. 토론 후 라벨로 계산하면 무의미하다.

**목표**: Cohen's κ ≥ 0.6 (Landis & Koch 1977, "substantial agreement")
